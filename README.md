# Logic Viewer

Visualize 4-, 8-, and 16-bit operations as pixel tables.

Read the [Shape of Logic article](https://cb341.dev/blog/shape-of-logic/).

Open [index.html](index.html) in a WebGL-capable browser.

Generate the 8-bit PNG gallery with:

```sh
node render_8bit_tables.js
```

Open [table.html](table.html) to view every operator and palette.
